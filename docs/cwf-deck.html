Solana Track ($100K/10) · Crypto World's Fair · Native Android + APK

The Problem

The next billion users arrive on mobile with a wallet already in their pocket. But phones are the weakest custody surface — seed phrases leak, keychains get scraped. The best wallet is the one you don't have to think about.

What It Is

Self-custody Solana wallet built on the Solana Mobile Stack with Mobile Wallet Adapter, Jetpack Compose, Kotlin. Every transaction is authorized inside your existing MWA wallet (Phantom, Solflare, Solana Seeker) over a secure local WebSocket — Selene sends unsigned payloads and receives signed txs. No seed, no private key, no keystore on disk.
