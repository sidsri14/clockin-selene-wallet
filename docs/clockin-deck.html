Selene

A privacy-first mobile Solana wallet — your keys never touch the phone.
CLOCK IN · Solana Mobile Hackathon · $135K pool · Native Android + APK + MWA

The Pitch

Seeker's next billion users arrive on mobile with a wallet already in their pocket. Selene is the wallet for the Solana smartphone era: self-custody, one screen, zero telemetry. Keys never live on the device — every transaction is authorized inside the user's existing MWA wallet (Phantom, Solflare, Seeker) over a secure local link.

Why It's Mobile-First (not a web wrapper)

  • Built on Mobile Wallet Adapter with LocalAssociationScenario — a real local WebSocket association session with 90s grace window, launched via association intent.
  • Native Jetpack Compose + Kotlin; single-screen balance/send/activity UX designed for a phone, not a browser.
  • Deep Solana network interaction: SOL legacy transfers, SPL USDC via Token Program v3, and automatic ATA creation for recipients without a USDC account — all in one byte-exact message.
